mainly

a multi-domain mail client self-hosted, lightning fast, highly configurable.

try demo github

One container and a database. Docker is the only requirement.

git clone https://github.com/crnst8/mainly && cd mainly && ./mainly.sh start

The script generates its own secrets, brings up Postgres and the app, and prints the address to open. Then ./mainly.sh user you@yourdomain.com creates your login and you add mailboxes from the UI. Full instructions, environment variables and an upgrade path are in the README.
